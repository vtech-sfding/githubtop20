# GitHub Hot Python Projects Analysis (English)

[中文版](README.md)

This project fetches hot Python repositories from the GitHub Search API and generates visualization pages plus blog-ready Markdown output.

## Project Files and Their Roles

The table below explains the purpose of each major file in this project.

| File | Type | Purpose | Notes |
|---|---|---|---|
| python_repos_visual_cn_top10.py | Python script | Fetches hot Python repositories and generates the main dashboard page. | The filename says top10, but the current implementation outputs Top 20. |
| python_repos_category_analysis_cn.py | Python script | Classifies Top 20 repos by keyword rules (AI, Python, Skills, Coding Assistance) and builds a category analysis page. | Includes 2x2 pie charts and repo lists. |
| python_repos_top20_blog_list_cn.py | Python script | Builds a blog-friendly Top 20 Markdown list and an HTML copy page. | Produces both md and html outputs. |
| github_hot_python_top20_cn.html | HTML page | Main dashboard (Top 20, dynamic switch between Stars/Forks, detailed cards). | Generated by python_repos_visual_cn_top10.py. |
| github_hot_python_top20_category_analysis_cn.html | HTML page | Category analysis view (AI/Python/Skills/Coding Assistance ratio). | Generated by python_repos_category_analysis_cn.py. |
| github_hot_python_top20_blog_list.md | Markdown | Top 20 repository list with bilingual descriptions and key metrics. | Generated by python_repos_top20_blog_list_cn.py. |
| github_hot_python_top20_blog_list.html | HTML page | Markdown copy helper page with one-click copy button. | Generated by python_repos_top20_blog_list_cn.py. |
| github_hot_python_top10_cn.html | HTML page | Earlier Top 10 dashboard artifact. | Static output kept for comparison/history. |
| github_stars_chart.html | HTML page | Earlier chart export artifact (large file with embedded Plotly script). | Static output file. |
| .gitignore | Config | Ignores Python caches, virtual envs, and common editor temp files. | Version-control support file. |

## Requirements

- Python 3.9+
- Network access to GitHub API

## Required Packages

Third-party packages needed by the scripts:

- requests
- plotly

Install:

```bash
pip install requests plotly
```

Optional (recommended virtual environment):

```bash
python -m venv .venv
# Windows
.\\.venv\\Scripts\\activate
# macOS/Linux
# source .venv/bin/activate

pip install requests plotly
```

## How to Use

### 1) Optional: set GitHub token (recommended)

To increase GitHub API rate limits, set GITHUB_TOKEN.

Windows PowerShell:

```powershell
$env:GITHUB_TOKEN = "your_token"
```

macOS/Linux:

```bash
export GITHUB_TOKEN="your_token"
```

The scripts can still run without a token, but rate limiting may happen sooner.

### 2) Run scripts

Main dashboard:

```bash
python python_repos_visual_cn_top10.py
```

Category analysis page:

```bash
python python_repos_category_analysis_cn.py
```

Blog Markdown list + copy page:

```bash
python python_repos_top20_blog_list_cn.py
```

### 3) Open generated outputs

After running scripts, open these files from the project folder:

- github_hot_python_top20_cn.html
- github_hot_python_top20_category_analysis_cn.html
- github_hot_python_top20_blog_list.html
- github_hot_python_top20_blog_list.md

## Data and Logic Notes

- Data source: GitHub Search API
- Query strategy: prefers hot Python repos active in the last 30 days; if fewer than 20 are found, falls back to a broader high-star query
- Classification strategy: keyword-based matching on repository name, description, topics, and homepage

## FAQ

1. Request failed or timed out
- Check network connectivity
- Retry later
- Use GITHUB_TOKEN for better rate limits

2. Results differ from previous runs
- Stars/activity/ranking on GitHub are dynamic and change over time

3. Script name does not match output size
- python_repos_visual_cn_top10.py currently generates a Top 20 dashboard; this is a naming legacy and does not affect functionality
